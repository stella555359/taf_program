Workflow

Template set now supports three built-in suggestions: leave it empty, choose ivy_26R1_vdt or ivy_26R2_vdt, or type any custom template set name directly in the same field. Manual template_names accepts separators like ;, ；, ,, ，, line breaks, or multiple spaces. Single spaces inside one template name are preserved. If both are provided, Portal merges template names from the selected template set and the manual input, removing duplicates.

Three supported modes: only template set, only template_names, or both together. At least one of them must be provided.

Examples: SBTS26R3_ENB_9999_260331_000003 -> SBTS26R3.ENB.9999.260331.000003. Env standard is Txxx or Txxxx. If a longer Env string is provided, Portal extracts and stores the standard Txxx/Txxxx code. Known Env mappings use the table below.

Each click on Create report timestamps lets you add one server-time source range with its own split interval. Portal expands each created source range, then merges all resulting intervals into the final report_timestamps_list.

If the latest merged interval end time is still in the future, Portal waits until that server-time end time + 40 minutes before it starts calling Compass to generate reports.

Successful combined interval count: 1 = singe_report. 2-3 = compare_merge. 4 or more = horizontal_merge.

Generated filenames follow the detector rule, for example: exec20260325T120349_SBTS26R3.ENB.9999.260319.000005_T813.SCF_7UE_DL_Burst_1csv.xlsx.

Convert Scout report to Compass format

Workflow

This mode reads the Scout workbook sheet, filters rows by fuzzy DistName match, and writes one Compass-style sheet per DistName filter into the same workbook.

Manual DistName filters accepts separators like ;, ；, ,, ，, line breaks, or multiple spaces. Single spaces inside one filter are preserved.

Generated filenames follow the same detector-style naming rule using Build, Env, and Scenario, and Portal appends a scout suffix. Portal always reads the fixed Scout sheet Chart Data.
